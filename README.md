# Pokedex Frontend

An Angular Pokédex app: browse and search Pokémon, backed by [pokedex-backend](https://github.com/LSvargas25/pokedex-backend) (a small caching proxy in front of the public PokeAPI).

## Features

- Browse and search Pokémon
- Pokémon detail view

## Tech stack

- Angular
- TypeScript

## Getting started

```bash
npm install
npm start
```

Run `pokedex-backend` locally (or point the app at a deployed instance) for data.

## Status

Small learning/portfolio project demonstrating a full-stack setup (Angular frontend + a lightweight Node/Express backend) around a public API.
